# 助农商城后续开发路线

更新时间：2026-08-24

本路线按依赖关系、业务价值和生产风险排序。每个阶段完成后都必须补充后端测试、前端测试和必要的浏览器验收。

| 阶段 | 功能 | 优先级 | 完成条件 |
| --- | --- | --- | --- |
| 1 | 商品图片上传（拖拽、点击、移动端相册） | P0 | 农户无需填写图片链接即可提交审核 |
| 2 | 环境与数据隔离 | P0 | 开发/测试/生产配置和验收数据隔离 |
| 3 | 沙箱支付 | P0 | 创建支付、回调验签、幂等、超时关闭闭环 |
| 4 | 秒杀可靠性 | P0 | 库存冻结、补偿、对账和并发压测通过 |
| 5 | 物流 | P1 | 发货、物流状态和买家查询可用 |
| 6 | 评价 | P1 | 已完成订单可评价且不能重复评价 |
| 7 | 售后 | P1 | 申请、审核、退款和状态流转可追踪 |
| 8 | 管理与安全 | P1 | 统计、管理员分级、JWT 撤销、审计和监控 |
| 9 | 体验优化 | P2 | 拍照上传、图片裁剪、多图和历史图片复用 |

当前执行目标是阶段 1。移动端拍照明确放在阶段 9，不作为当前上传功能的前置条件。
