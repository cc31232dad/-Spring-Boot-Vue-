# 助农商城实施路线

本项目按可独立运行、可独立测试的增量拆分为八个阶段。每一阶段完成后再编写或确认下一阶段的详细计划，避免后期业务认知变化导致大范围返工。

1. **项目骨架、认证与 RBAC**：建立 Spring Boot、Vue、MySQL、Redis 基础工程，实现注册、登录、JWT 和三类角色授权。
2. **农户入驻与审核**：实现申请、材料上传、管理员审核、农户资料和操作日志。
3. **商品、分类与溯源**：实现商品审核、上下架、图片、库存、溯源批次和生产记录。
4. **消费者购物闭环**：实现搜索、收藏、购物车、地址、跨农户拆单、普通库存扣减和订单状态。
5. **支付宝沙箱支付**：实现支付创建、异步通知、验签、幂等、主动查单和超时取消。
6. **助农专区与 Redis 秒杀**：实现活动审核、库存预热、Lua 原子扣减、一人一单、落库失败补偿和库存恢复。
7. **履约、评价与运营后台**：实现发货、收货、评价、公告、轮播图、销售统计和运营看板。
8. **系统验收与论文材料**：完成权限测试、支付测试、JMeter 压测、部署文档、测试报告和答辩演示数据。

全程遵循测试先行、小步提交。第一阶段的详细执行计划见 `2026-07-19-foundation-auth-rbac.md`。
