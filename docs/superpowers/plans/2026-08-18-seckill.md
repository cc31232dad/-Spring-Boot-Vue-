# Redis 秒杀 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Add Redis-backed seckill activities with atomic Lua qualification, durable orders, compensation, cancellation, and a minimal usable frontend.

**Architecture:** Keep the existing modular Spring Boot structure. Add a `seckill` domain with MyBatis entities/mappers, an application service that coordinates MySQL and Redis, and REST endpoints protected by existing JWT/RBAC. Use Flyway for activity/order schema and a Redis Lua script for atomic stock and buyer state.

**Tech Stack:** Spring Boot 3.5, MyBatis-Plus, MySQL 8.4, Spring Data Redis, Redis Lua, Vue 3, Pinia, Vitest.

## Global Constraints

- Redis keys use `seckill:stock:{activityId}` and `seckill:buyers:{activityId}`.
- One user can succeed at most once per activity.
- Database failure after Redis reservation must restore both stock and buyer qualification.
- Existing ordinary cart/order behavior must remain unchanged.
- `.env` remains local-only.
